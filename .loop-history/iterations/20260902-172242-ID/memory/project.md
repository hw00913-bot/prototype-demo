# 项目记忆

## 项目定位

- 项目名称：大众通信重呼方式与人工确认
- 当前迭代：在已交付的智能外呼统一中台上，增加大众通信重呼方式选择、人工配置确认和末次呼叫判断。
- 创建日期：2026-09-02
- 类型：无构建步骤的静态前端原型
- 入口：`index.html`

## 产品目标

向外呼运营人员如实呈现大众通信平台的重呼限制：任务没有待呼号码时会变为已完成，已完成任务中的待重呼号码不会继续触发。中台支持选择“定时重呼”或“任务重呼”，并在无定时重呼配置接口的前提下，用人工确认、必填字段和可追溯记录形成业务门禁。

## 目标用户

- 外呼运营人员：关联大众通信任务并选择重呼方式。
- 业务管理员：复核人工配置记录和最后一次呼叫判断。
- 产品、研发和测试：评审平台边界、分支校验和字段口径。

## 核心页面列表

- `sys-scene`：大众通信平台配置区负责重呼方式、定时重呼参数、人工确认与风险知情。
- `scene-list`：大众通信任务详情只读展示重呼方式、人工确认记录、呼叫轮次与是否最后一次计划呼叫。
- `docs/interaction.html` 与 `docs/功能说明文档.md/.html`：记录交互、平台限制、字段定义和判断公式。

## 核心用户路径

- 进入业务场景并新建或编辑场景，选择大众通信。
- 填写大众任务 UUID，选择不重呼或需要重呼。
- 需要重呼时，默认选中带“推荐”标识的定时重呼，也可切换为任务重呼。
- 定时重呼要求填写关联重呼任务 ID、计划重呼次数，并勾选已在大众后台完成配置；任务重呼要求勾选已知悉完成态风险。
- 保存后在外呼任务详情中查看只读追溯信息。

## 主要数据对象

- 大众通信业务场景关联。
- 重呼配置：是否重呼、重呼方式、关联重呼任务 ID、计划重呼次数。
- 人工确认记录：确认状态、确认人、确认时间。
- 呼叫轮次判断：当前呼叫轮次、最大呼叫轮次、是否最后一次计划呼叫。

## 交付方式

直接修改当前静态原型，通过本地 HTTP 服务器演示；同步交付业务说明、验收与验证记录、S9 标注准备文件及用户明确要求的标注数据回写。

## 已确认假设

- 大众平台的定时重呼关联任务无可用配置接口，中台无法自动验证。
- 定时重呼是默认且推荐方式；任务重呼仍可选，但必须显式知悉风险。
- 计划重呼次数不包含首次呼叫；最大呼叫轮次等于计划重呼次数加一。
- 修改主任务 UUID、关联重呼任务 ID、计划重呼次数或重呼方式时，原人工确认失效。
- 演示用确认人为当前用户“管理员”，确认时间使用浏览器当前时间。
