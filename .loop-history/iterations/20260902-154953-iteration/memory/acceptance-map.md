## 验收流程

### 验收步骤
1. 按步骤顺序执行验收
2. 每个步骤完成后标记状态
3. 发现问题记录到问题清单
4. 问题修复后重新验收
5. 所有步骤验收通过后完成S7阶段

- DOM检查：浏览器开发者工具
- 控制台检查：浏览器控制台
- 网络检查：浏览器网络面板
