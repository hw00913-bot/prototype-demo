## 产品形态

- 面向类型：B2B 智能外呼平台产品演示。
- 载体形态：静态 HTML 原型（无构建步骤）。
- 主要使用角色：技术团队（了解产品功能和接入流程）。

## 项目目的

- 实现目的：整合多个接入方原型，展示智能外呼平台的完整能力。
- 评审对象：技术团队，用于了解产品功能和接入流程。
- 需要验证的业务假设：整合后的原型能清晰展示各平台能力差异和共性。
- 不属于本次验证目标：不涉及真实业务逻辑实现、不涉及后端接口对接。

## 项目范围

- 本期模块：外呼场景、统计分析、外呼结果、系统管理。
- 本期页面：首页、外呼列表、外呼拦截、通话统计、计费统计、线索统计、通话记录、线索记录、业务场景、标签管理、租户管理。
- 本期能力：多平台数据展示、筛选查询、导出模拟、Tab切换、级联选择。
- 核心流程：外呼任务管理 → 通话记录查看 → 统计分析 → 系统配置。

## 非本期范围

- 不做模块：用户权限管理、工作流审批、实时监控大屏。
- 不做页面：登录页、个人中心、系统设置、帮助文档。
- 不做能力：实时数据更新、WebSocket推送、复杂图表交互。

## 整体页面结构

- 导航结构：左侧边栏，按业务模块分类（外呼场景、统计分析、外呼结果、系统管理）。

- 页面职责：每个页面展示特定功能模块的数据和操作。

## 核心流程

- 用户入口：首页展示概览数据。
- 主流程步骤：外呼列表 → 外呼任务详情 → 通话记录 → 线索记录 → 统计报表。
- 关键状态：任务状态（进行中/暂停/已终止）、通话状态（已接通/未接通/占线等）。
- 异常或空状态：数据为空时的友好提示。

## 验收方向

- 本轮完成后应看到：一个功能完整、数据丰富的智能外呼平台演示原型。

- 必须跑通流程：外呼列表筛选 → 查看通话记录 → 查看统计报表。
