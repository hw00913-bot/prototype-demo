# 现有充值功能基线

## 资料记录

- 资料名称：智能外呼中台现有充值功能
- 位置：当前原型项目
- 版本：当前工作区版本
- 日期：2026-09-04
- 提供者：原型源码与功能说明文档

## 可核对的现有事实

1. 功能入口为：系统管理 → 租户管理 → 租户操作列“充值管理”。
2. 充值管理抽屉已有三个 Tab：计费明细、充值单管理、余额调整。
3. 充值单管理已包含付费单/试用单分支、充值单号读取、确认关联、历史单据和逐单生效。
4. 现有口径是：充值金额进入统一资金账户；大模型和小模型的可用分钟数按各自默认单价换算，不可相加。
5. 现有说明将 D智链定义为外部充值单来源，但本轮尚未提供对应接口文档。

## 可定位来源

- `docs/功能说明文档.md`，第 14 节“系统管理 - 租户管理 - 充值管理抽屉”。

## 现场观察（非新需求）

- 2026-09-04 通过浏览器点击“重庆东风南方渝兴”的“充值管理”时，抽屉未打开。
- 控制台错误为 `ReferenceError: validity is not defined`，定位到 `js/pages/sys-tenant.js` 的历史充值单渲染逻辑。

上述观察只是底座现状；是否纳入本轮迭代范围，需由用户确认。
