# 业务术语

| 术语 | 定义 | 来源 | 状态 |
|---|---|---|---|
| 充值管理 | 按租户管理计费明细、充值单和余额调整的现有功能容器 | `docs/功能说明文档.md` | 现有基线 |
| 充值单管理 | 关联付费单或试用单，并在确认后将单据进入待生效或已生效状态 | `docs/功能说明文档.md` | 现有基线 |
| 单据生效 | 将已关联且符合条件的充值单资产计入租户有效期或统一资金账户 | `docs/功能说明文档.md` | 现有基线 |
| 余额调整 | 不关联充值单的线下资金扣减操作 | `docs/功能说明文档.md` | 现有基线 |
| D智链 | 现有说明中的外部充值单来源系统 | `docs/功能说明文档.md` | 待接口资料核验 |
| 标准版（年包） | 单店一年服务套餐，价格 5,000 元，包含 10,000 通讯分钟及图中列明的平台与运营服务 | `inputs/attachments/recharge-pricing-rules-20260904.png` | 新需求 |
| 话费充值包 | 服务期内按需购买的分钟包，每个 1,000 元、包含 3,500 分钟，可多次叠加 | `inputs/attachments/recharge-pricing-rules-20260904.png` | 新需求 |
| 商用 | 租户标记之一，目前只用于展示，不改变套餐、冻结或消耗规则 | 用户需求 UA-20260904-002 | 新需求 |
| 试用 | 租户标记之一，目前只用于展示，不改变套餐、冻结或消耗规则 | 用户需求 UA-20260904-002 | 新需求 |
| 通讯分钟 | 电话接通后计量的通话时长，单次不满 1 分钟按 1 分钟计算 | `inputs/attachments/recharge-pricing-rules-20260904.png` | 新需求 |
| 使用情况 | 从中台右上角查看当前租户有效期、余额和使用明细的自助入口 | 用户需求 UA-20260904-003 | 新需求 |
| 当前租户 | 多租户账号当前登录所处的租户，使用情况只能展示该租户数据 | 用户需求 UA-20260904-004 | 已确认 |
| 可用分钟数 | 当前租户统一分钟池中可继续用于外呼的通讯分钟余额，在使用情况中以“分钟”为单位展示 | 用户需求 UA-20260904-004、UA-20260904-008 | 已确认 |
| 统一分钟池 | 标准版年包、话费充值包及手工分钟调整形成的分钟汇入同一租户级分钟池，由大模型与小模型外呼共同冻结、释放和消耗 | 用户需求 UA-20260904-008 | 已确认 |
| 按日使用明细 | 以日期为粒度汇总当前租户当日消耗的通话分钟数 | 用户需求 UA-20260904-004 | 已确认 |
| 任务级使用明细 | 按日明细的二级页面，展示该日每个具体任务及其消耗的通话分钟数 | 用户需求 UA-20260904-004 | 已确认 |
| 使用时长 | 充值后本次服务可使用的有效时长，在充值表单中以“天”为单位填写大于 0 的整数 | 用户需求 UA-20260904-005、UA-20260904-008 | 已确认 |
| 入账分钟数 | 本次充值成功后实际计入租户统一分钟池的分钟数，在充值表单中填写大于 0 的整数 | 用户需求 UA-20260904-005、UA-20260904-008 | 已确认 |
| 内部充值流水号 | 新充值提交成功后由中台自动生成的唯一追溯编号，不依赖外部充值单号 | 用户需求 UA-20260904-008 | 已确认 |
| 手工调增 | 不依赖外部充值单号，由有权限的充值管理员增加租户使用时长或可用分钟数，并生成内部调整流水 | 用户需求 UA-20260904-006、UA-20260904-007 | 已确认 |
| 手工调减 | 不依赖外部充值单号，由有权限的充值管理员减少租户使用时长或可用分钟数，并生成内部调整流水 | 用户需求 UA-20260904-006、UA-20260904-007 | 已确认 |
