## 2. 页面明细

### PAGE-001 · 租户管理列表与编辑

- 菜单路径：系统管理、租户管理
- 适用角色：平台管理员、充值管理员
- 承载场景：SC-001、SC-002、SC-003、SC-005、SC-009
- 页面状态：loading、loaded、empty、error、editing、saving

字段：

- **租户名称/租户 ID**：识别充值与手工调整的对象。
- **租户类型**：保留现有租户类型字段。
- **商用/试用标记**：新建、编辑可选，列表与充值管理中可识别展示。
- **当前有效期/可用分钟**：展示当前有效期与租户统一分钟池可用分钟，作为进入充值管理前的账户概览。

操作：

- **ACTION-001 · 保存租户商用/试用标记**：来源场景 SC-001；权限 tenant:edit
- **ACTION-002 · 打开充值管理**：来源场景 SC-002、SC-003、SC-005、SC-009；权限 recharge:view

原型验收点：

- AC-001：商用/试用标记可保存。
- AC-002：列表以标签展示商用/试用。
- AC-003：仅改标记不触发计费规则变更。

### PAGE-002 · 租户充值管理

- 菜单路径：系统管理、租户管理、充值管理
- 适用角色：充值管理员
- 承载场景：SC-002、SC-003、SC-005、SC-009
- 页面状态：loading、loaded、empty_history、error

字段：

- **租户信息**：只读展示租户名称、ID 和商用/试用标记。
- **账户概览**：展示有效期、统一分钟池可用分钟数、冻结额度和呼叫可用状态。
- **内部充值记录**：展示内部流水号、租户、充值类型、数量、价格、实际使用时长、实际入账分钟数、调整前后值、操作人、操作时间、原因和状态。
- **手工调整流水**：展示调增/调减、使用时长/可用分钟、调整前后值、原因、操作人和时间。

操作：

- **ACTION-003 · 开通标准版**：来源场景 SC-002；权限 recharge:create
- **ACTION-004 · 购买话费充值包**：来源场景 SC-003；权限 recharge:create
- **ACTION-005 · 发起手工调整**：来源场景 SC-009；权限 recharge:adjust
- **ACTION-006 · 重试加载**：来源场景 SC-005；权限 recharge:view

原型验收点：

- 充值管理不展示外部充值单号作为新充值前置条件。
- AC-018/AC-029：系统自动生成内部流水号并保存完整充值字段，实际分钟进入统一分钟池。
- 充值记录与手工调整流水可分别追溯。
- 无历史时展示空状态，加载失败时可重试。

### PAGE-003 · 套餐开通与充值包表单

- 菜单路径：系统管理、租户管理、充值管理、新增充值
- 适用角色：充值管理员
- 承载场景：SC-002、SC-003
- 页面状态：initial、editing、validation_error、submitting、success、error

字段：

- **充值类型**：标准版年包或话费充值包。
- **套餐价格/充值包单价**：只读展示 5,000 元/店或 1,000 元/包。
- **充值包数量**：充值包模式可选，用于计算默认分钟数。
- **使用时长**：按套餐规则带入默认值，以天为单位手工编辑，只允许大于 0 的整数。
- **入账分钟数**：标准版默认 10,000 分钟；充值包默认按数量 × 3,500，允许编辑为大于 0 的整数，成功后计入统一分钟池。
- **偏离默认值原因**：使用时长或入账分钟数任一值偏离套餐默认值时必填；未偏离时非必填。
- **生效结果预览**：展示预计生效时间、有效期与入账后统一分钟池可用分钟。

操作：

- **ACTION-007 · 提交充值**：来源场景 SC-002、SC-003；权限 recharge:create
- **ACTION-008 · 取消充值**：来源场景 SC-002、SC-003；权限 recharge:create

原型验收点：

- AC-027：使用时长与入账分钟数均可编辑。
- AC-028：未修改使用默认值，修改后以提交值生效。
- AC-030：使用天数和分钟数须为大于 0 的整数；偏离默认值须填写原因；通过后无需额外审批。
- AC-036：实际入账分钟数进入大/小模型共用的统一分钟池。
- 不要求输入外部充值单号。

### PAGE-004 · 手工调增/调减弹窗

- 菜单路径：系统管理、租户管理、充值管理、手工调整
- 适用角色：充值管理员
- 承载场景：SC-009
- 页面状态：initial、editing、validation_error、submitting、success、conflict、error

字段：

- **调整方向**：必选调增或调减。
- **调整对象**：必选按天记录的使用时长或统一分钟池可用分钟数；两个方向均支持两种对象。
- **调整值**：按对象展示对应单位与取值校验。
- **调整原因**：必填，用于内部审计和历史追溯。
- **调整前/后值**：提交前预览当前值和预计结果。
- **冻结边界**：只读提示已冻结额度，调减不直接修改冻结记录。

操作：

- **ACTION-009 · 确认手工调整**：来源场景 SC-009；权限 recharge:adjust
- **ACTION-010 · 取消手工调整**：来源场景 SC-009；权限 recharge:adjust

原型验收点：

- AC-031：调增/调减均可调整按天使用时长或统一分钟池可用分钟。
- AC-032：不依赖外部充值单号。
- AC-034：调减不篡改冻结记录，不得减为负数。
- AC-035：方向、对象、调整值或原因缺失时阻止提交。

### PAGE-005 · 当前租户使用情况与按日明细

- 菜单路径：右上角、使用情况
- 适用角色：租户用户（不含超级管理员）
- 承载场景：SC-008
- 页面状态：loading、loaded、empty_daily_usage、expired、error

字段：

- **当前登录租户**：只读展示，多租户账号仅查看当前登录租户。
- **有效期起止时间/有效状态**：展示当前租户服务期及正常/已过期等状态。
- **可用分钟数**：以分钟为单位展示大/小模型共用的统一分钟池余额，不展示金额余额。
- **日期**：一级明细的按日汇总维度。
- **当日消耗通话分钟**：与二级任务明细合计保持一致。

操作：

- **ACTION-011 · 打开使用情况**：来源场景 SC-008；权限 usage:view_current_tenant
- **ACTION-012 · 查看当日任务明细**：来源场景 SC-008；权限 usage:view_current_tenant
- **ACTION-013 · 重试加载使用情况**：来源场景 SC-008；权限 usage:view_current_tenant

原型验收点：

- AC-019：非超级管理员的租户用户可见右上角入口。
- AC-020：展示有效期和当前状态。
- AC-021/AC-036：余额展示统一分钟池可用分钟数，大/小模型不分池。
- AC-022：一级明细按日展示消耗分钟。
- AC-023/AC-026：强制当前租户隔离且超级管理员不提供该功能。

### PAGE-006 · 每日任务通话分钟消耗明细

- 菜单路径：右上角、使用情况、按日明细、任务明细
- 适用角色：租户用户（不含超级管理员）
- 承载场景：SC-008
- 页面状态：loading、loaded、empty、error

字段：

- **当前租户/选中日期**：只读展示下钻条件。
- **任务名称/任务标识**：识别当日产生通话分钟消耗的具体外呼任务。
- **任务消耗通话分钟**：展示单个任务在该日从统一分钟池结算的消耗分钟数。
- **当日合计**：必须与一级页面当日汇总值一致。

操作：

- **ACTION-014 · 返回按日使用明细**：来源场景 SC-008；权限 usage:view_current_tenant
- **ACTION-015 · 重试加载任务明细**：来源场景 SC-008；权限 usage:view_current_tenant

原型验收点：

- AC-025：展示指定日期每个具体任务的消耗分钟，且合计与当日汇总一致。
- AC-024：无数据时显示空状态，加载失败时可重试。
- 二级页面继续使用当前登录租户的服务端租户上下文。
