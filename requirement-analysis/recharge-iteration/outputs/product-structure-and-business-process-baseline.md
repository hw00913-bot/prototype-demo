# 产品结构与业务流程确认基线

> 项目：智能外呼中台充值功能迭代  
> 生成时间：2026-09-04T18:30:43+08:00

## 1. 产品目标

将租户充值改为标准版年包与话费充值包模式，去除外部充值单号依赖，以内部流水管理充值并将分钟汇入大/小模型共用的统一分钟池；保留冻结消耗与手工调整闭环，并为租户用户提供当前租户的有效期、可用分钟和两级使用明细。

## 2. 确认范围

### 本期范围

- 租户新增商用/试用展示标记
- 标准版年包：5,000 元/店，默认一年、默认 10,000 分钟及对应服务说明
- 话费充值包：1,000 元/包，默认 3,500 分钟，服务期内可叠加
- 充值表单的使用时长和入账分钟数可手工编辑
- 充值使用时长按天填写，使用时长与入账分钟数均为大于 0 的整数；偏离默认值必须填写原因且无需额外审批
- 标准版、充值包和手工分钟调整进入大/小模型共用的租户级统一分钟池
- 保留原有额度冻结、释放与实际消耗闭环
- 已接通通话不满 1 分钟按 1 分钟消耗
- 新充值不依赖外部充值单号，系统自动生成内部流水号并记录完整充值字段
- 右上角当前租户使用情况：有效期、可用分钟、按日消耗和任务级二级明细
- 手工调增与调减均可调整使用时长或可用分钟数

### 非本期范围

- 新充值读取或关联 D智链等外部充值单
- 商用与试用租户的差异化套餐、冻结或消耗规则
- 超级管理员的右上角使用情况和明细功能

## 3. 角色与系统边界

### 角色

- **平台管理员**：负责新建、编辑租户并维护商用/试用标记。
- **充值管理员**：负责标准版开通、话费充值包购买、充值记录查看及使用时长/可用分钟的手工调增调减。
- **租户运营人员**：发起外呼任务，任务继续沿用原有额度冻结、释放和消耗规则。
- **租户用户**：从右上角查看当前登录租户的有效期、可用分钟、按日消耗和任务级明细。
- **超级管理员**：不提供右上角使用情况及其明细功能。

### 系统

- **智能外呼中台**：承载租户管理、充值管理、使用情况和外呼任务管理。
- **租户管理服务**：保存租户基本信息与商用/试用标记。
- **充值服务**：校验并执行标准版开通、话费充值包购买和内部充值记录。
- **内部额度账本**：管理租户有效期、统一分钟池、冻结、实际消耗、完整内部充值流水和手工调整流水。
- **外呼任务系统**：在任务启动、完成或终止时与额度账本完成冻结、结算和释放。
- **D智链**：原外部充值单来源；新充值流程已确认不再读取或关联该系统。

## 4. 产品能力结构

- **租户管理**：维护租户基本信息、商用/试用标记并作为充值管理的租户入口。
- **充值管理**：承载套餐概览、标准版开通、话费充值包、统一分钟池状态、完整内部充值流水和手工调整流水。
- **手工调整**：支持调增/调减使用时长或可用分钟，并展示调整前后值与审计流水。
- **使用情况**：向非超级管理员的租户用户提供当前租户的有效期、可用分钟、按日消耗与任务级明细。
- **通讯额度账本**：统一承载标准版、充值包和手工调整入账，以及大/小模型任务冻结、通话消耗与释放。

## 5. 业务流程

### FLOW-001 · 租户服务开通与充值

关联场景：SC-001、SC-002、SC-003、SC-005

1. 为租户维护商用/试用标记
2. 开通标准版年包，将实际分钟计入统一分钟池并生成内部流水
3. 有效服务期内按需购买话费充值包，将实际分钟叠加至统一分钟池
4. 在充值管理中核对当前状态与完整内部流水

### FLOW-002 · 通讯额度占用与结算

关联场景：SC-004、SC-008

1. 大/小模型外呼任务从统一分钟池预冻结通讯额度
2. 接通通话按分钟规则形成实际消耗
3. 任务完成或终止时结算并释放未使用冻结
4. 租户用户查看统一分钟池可用分钟与按日/任务消耗

### FLOW-003 · 租户账户手工调整

关联场景：SC-009、SC-005

1. 选择调增/调减与按天使用时长/统一分钟池可用分钟数
2. 输入调整值和原因并预览结果
3. 通过边界校验后更新账户
4. 生成内部调整流水并在充值管理中可查

## 7. 核心状态模型

### 租户服务期状态

状态：未开通、有效、已过期

转换：未开通 → 有效：标准版开通成功、有效 → 有效：手工调增/调减使用时长且调整后仍有效、有效 → 已过期：有效期届满或手工调减后到期、已过期 → 有效：续费或手工调增使用时长成功

### 通讯额度生命周期

状态：可用、已冻结、已消耗、已释放

转换：可用 → 已冻结：外呼任务预占额度、已冻结 → 已消耗：已接通通话按规则结算、已冻结 → 已释放：任务完成、终止或触发原有释放条件、已释放 → 可用：未消耗额度返回可用余额

### 内部充值与调整操作状态

状态：编辑中、校验失败、处理中、已生效、失败

转换：编辑中 → 校验失败：时长/分钟不是大于 0 的整数、偏离默认值缺少原因、权限或其他必填项不合法、编辑中 → 处理中：提交并通过校验、处理中 → 已生效：账本更新与内部流水一致写入、处理中 → 失败：账本写入失败或发生版本冲突、失败 → 编辑中：刷新当前值后重新确认

## 8. 假设与约束

- 历史外部充值单和历史金额调整记录在用户确认迁移口径前保留原数据，不自动换算或删除。
- 已有租户的续费有效期起点在 ISSUE-006 确认前不静默覆盖当前有效期。
- 话术修改幅度正好 50% 的处理方式仍由 ISSUE-008 跟踪。
- 现有原型中有历史充值单的租户无法打开充值管理的缺陷是否纳入本轮仍由 ISSUE-002 跟踪。
