四. 功能说明

1. 首页 - 用量余额

1）功能名称： 用量余额

2）交互说明： 进入首页后直接展示当前演示租户的余额、有效期和呼叫控制状态，无额外操作。

3）数据来源： SRC-009；当前 Mock 租户、计费规则、充值历史、冻结任务和余额调整数据。

4）逻辑说明： 可用分钟数按已生效充值与余额调整计算，并扣除已消费及冻结占用；有效期取可用配置中的最近有效范围；呼叫控制结合余额、有效期和控制状态判断。

5）功能明细： 见下表。

功能名称功能说明数据来源取值逻辑数据格式默认值异常处理
大/小模型可用分钟数分别展示两类模型可用于外呼的分钟数SRC-009 / Mock 计费数据可用余额按对应模型的单价折算为分钟并扣除占用分钟数0缺少有效价格配置时不推算虚假分钟数
呼叫控制状态提示当前租户是否具备发起呼叫条件余额、有效期、控制状态余额与有效期有效且控制开关允许时显示可发起状态标签不可发起数据不足时按不可发起处理

2. 外呼场景 - 外呼列表

1）功能名称： 外呼任务筛选、任务列表与任务详情

2）交互说明： 用户按名称、状态、平台查询；点击任务卡片打开详情抽屉。详情按平台展示差异字段；厚朴提供令牌失效演示，大众任务信息为只读。

3）数据来源： SRC-001~SRC-006；FLD-001~FLD-015。

4）逻辑说明： 筛选条件为同时满足；卡片数量区分已分配、待处理和已呼叫；详情统一基础字段并追加平台特有字段。

功能名称功能说明数据来源取值逻辑数据格式默认值异常处理
外呼任务筛选按任务名、任务状态、所属平台缩小列表FLD-003、004、006非空条件按 AND 组合，平台名称严格匹配文本/枚举全部无匹配时展示空列表并提示查询完成
外呼任务列表展示六平台任务及执行进度FLD-001、003、004、006~009待处理 = 已分配 - 已呼叫；状态按统一枚举展示卡片/状态标签/数字Mock 全量字段缺失时按页面兜底值展示
任务详情查看基础信息、名单和平台差异配置FLD-001~015按选中任务平台决定详情区块抽屉首个详情页签外部详情未返回时展示明确空状态

3. 外呼场景 - 外呼黑名单

1）功能名称： 黑名单分组、号码维护与平台同步

2）交互说明： 选择分组后筛选号码；可新增、批量导入、导出、移动、移除、重试同步或维护同步设置。

3）数据来源： SRC-003；FLD-070~FLD-075。

4）逻辑说明： 号码归属一个黑名单组，添加类型、原因、来源、有效期和同步状态分别记录；批量动作只对已选行生效。

功能名称功能说明数据来源取值逻辑数据格式默认值异常处理
黑名单筛选按号码、添加类型、添加时间查询FLD-071、073、074非空条件同时匹配当前分组记录文本/枚举/日期全部开始时间晚于结束时间时应阻止查询
平台同步状态展示号码与外部平台同步结果FLD-075映射为已同步或同步失败等状态状态标签待同步失败记录可选择后重试

4. 统计分析 - 通话统计

1）功能名称： 外呼统计/客户统计、筛选与统计列表

2）交互说明： 切换统计口径后替换表格；按日期、场景、平台查询，重置恢复默认条件。

3）数据来源： SRC-001、002、003、005、006；FLD-006、040~045。

4）逻辑说明： 接通率 = 接通总数 / 拨打总次数；触达率按当前列表的名单口径计算；分母为 0 时展示 0%。

功能名称功能说明数据来源取值逻辑数据格式默认值异常处理
通话统计列表展示每日场景和平台的呼叫效果FLD-006、040~045按日期、场景、平台聚合呼叫、接通、未接通和时长数字/百分比/时长外呼统计无数据时展示空状态；分母为 0 显示 0%

5. 统计分析 - 计费统计

1）功能名称： 计费口径、计费筛选、汇总与明细

2）交互说明： 按日期、租户和平台查询；点击列表详情打开计费明细弹窗。

3）数据来源： SRC-003、005、006、009；FLD-006、050、055。

4）逻辑说明： 客户接通才计费，按分钟收费，不满 1 分钟按 1 分钟计；当前原型展示计费时长和模型类型，不虚构真实费用。

功能名称功能说明数据来源取值逻辑数据格式默认值异常处理
计费统计列表展示租户、平台、模型类型与计费时长SRC-009 / MockBillingStatsRows筛选后按行展示汇总数据日期/文本/分钟全部平台无匹配数据时展示空表
计费明细追溯汇总行对应的明细记录MockBillingDetail按汇总记录 ID 关联明细弹窗表格当前汇总行无明细时显示“暂无数据”

6. 统计分析 - 线索统计

1）功能名称： 线索汇总、线索明细与线索回流

2）交互说明： 主 Tab 切换三种报表；汇总和明细可在 NEV/ICE 间切换，再按时间、业务类型、场景、意向或门店过滤。

3）数据来源： SRC-010；FLD-020、021、023~025、031、040、041、043、045。

4）逻辑说明： 汇总展示导入、外呼、接通、下发及 A~E 意向分级；明细下钻到手机号、场景、通话状态和意向；回流统计比较传入、提交外呼和回流数量。

功能名称功能说明数据来源取值逻辑数据格式默认值异常处理
线索统计列表展示 NEV/ICE 的批次汇总MockClueStatNEV/ICE按导入日期和业务类型聚合数字/百分比/时长NEV分母为 0 的比例显示 0%

7. 外呼结果 - 通话记录

1）功能名称： 通话记录筛选、列表与详情

2）交互说明： 基础条件可直接查询，展开后增加场景、状态和平台；点击详情打开录音、转写、摘要和平台字段。

3）数据来源： SRC-001、002、003、005、006；FLD-020~036。

4）逻辑说明： 时间、状态和平台按统一字段展示；大众详情通过其呼叫标识模拟查询，未返回时展示明确占位状态。

功能名称功能说明数据来源取值逻辑数据格式默认值异常处理

通话详情查看录音、对话文本、摘要与标签FLD-026、028~036按选中记录关联详情数据弹窗当前记录详情未返回时显示未返回状态

8. 外呼结果 - 线索记录

1）功能名称： 线索记录筛选、列表、客户标签与回访详情

2）交互说明： 按电话、回访时间、通话状态、场景和意向查询；点击“查看”打开客户标签，点击“详情”打开多次回访抽屉。

3）数据来源： SRC-003、004、006；FLD-020、021、024~027、031、036。

4）逻辑说明： 一条线索聚合多次回访，列表展示最后回访状态与意向，详情按时间顺序展示每次回访。

功能名称功能说明数据来源取值逻辑数据格式默认值异常处理

线索多次回访详情查看各次回访时间、状态、记录和意向线索 revisits 数据按选中线索展开回访数组抽屉表格当前线索无回访时展示空记录

9. 系统管理 - 业务场景

1）功能名称： 场景列表、通用表单与六平台差异配置

2）交互说明： 筛选或查看场景；点击新建打开抽屉，填写通用字段后选择一个智能平台，页面只展示该平台专属配置，保存前执行必填校验。

3）数据来源： SRC-001~SRC-006；FLD-002、003、006、012~015。

4）逻辑说明： 平台为互斥单选；一知、中科金关联外部任务和模型账号，电声包含呼叫时段/重呼/黑名单/启动策略，冰兰包含通道/机器人/时段/拦截，厚朴关联任务名称与数据列模式，大众通过 UUID 关联且策略在 SaaS 侧维护。

功能名称功能说明数据来源取值逻辑数据格式默认值异常处理
智能平台选择决定当前场景使用的平台及专属表单FLD-006六个平台互斥单选，切换后隐藏其他平台面板单选未选择未选择平台时阻止保存
电声平台配置配置机器人、呼叫时段、重呼、黑名单和启动策略SRC-003场景类型匹配机器人；至少一个完整呼叫时段组合表单自动启动开启时段不完整或必填缺失时阻止保存

10. 系统管理 - 标签管理

1）功能名称： 标签配置树、中台标签与供应商标签映射

2）交互说明： 在左侧树选择中台或供应商、租户类型和场景；右侧维护标签启停、名称、排序及供应商到中台的映射；工具栏可维护场景和供应商。

3）数据来源： SRC-007、003、006；FLD-060~063。

4）逻辑说明： 中台标签是统一标准，供应商标签保留原生语义并映射到中台标签；停用供应商或场景时禁止继续修改其标签配置。

功能名称功能说明数据来源取值逻辑数据格式默认值异常处理
标签配置树按标签体系、租户类型和场景定位配置上下文MockTagSuppliers/MockTagScenes点击叶子节点加载对应配置树首个可用节点节点停用时右侧进入只读/禁用状态
供应商标签映射将供应商原生标签映射到中台标准标签FLD-060~063启用供应商标签后选择一个本地标签映射表格/下拉未映射目标标签不存在时保持未映射并提示

11. 系统管理 - 租户管理

1）功能名称： 租户筛选、租户表单、计费配置、充值与余额管理

2）交互说明： 按名称筛选；可新建/编辑租户；从列表进入大/小模型计费配置或充值管理抽屉，处理充值关联、生效和余额调整。

3）数据来源： SRC-002、009；FLD-050~055。

4）逻辑说明： 租户信息与计费信息分离维护；充值单关联后可按套餐规则生效；余额调整记录单独留痕；呼叫控制结合有效期、余额和控制状态。

功能名称功能说明数据来源取值逻辑数据格式默认值异常处理
租户列表展示租户基础信息、余额、有效期和呼叫状态FLD-050~055关联租户、价格规则、充值与余额数据生成展示摘要表格全量租户计费数据缺失时不虚构余额
租户计费配置维护大模型/小模型价格与启用状态SRC-009 / FLD-055按租户和模型类型保存配置弹窗表格现有配置价格格式非法时阻止保存
