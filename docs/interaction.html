3）数据来源：SRC-002、SRC-004、SRC-005；FLD-001、FLD-002、FLD-003、FLD-006、FLD-007、FLD-008、FLD-021、FLD-022；权限口径见 SRC-016、FLD-005、FLD-031。

2. 充值管理 - 标准版、试用套餐与话费充值包

1）功能名称：标准版开通、试用套餐、话费充值包与内部流水。

2）交互说明：超级管理员从租户列表进入充值管理。试用租户仅显示“开通试用套餐”，表单仅有“试用套餐”一种充值类型；商用租户仅显示“标准版开通”和“话费充值包”，表单仅有这两种商业配置。打开和提交均校验当前租户类型，禁止使用另一类型的配置；表单打开后租户标记变化也须重新校验。试用套餐默认 0 元、30 天、500 分钟；开通保留试用标记。表单载入商品默认价格、天数和分钟；用户可编辑本次套餐总价、实际使用天数及实际入账分钟，预览生效时间、失效时间和余额变化后提交。

3）数据来源：SRC-002、SRC-003、SRC-004、SRC-005、SRC-008、SRC-010、SRC-012、SRC-013、SRC-014；FLD-009 至 FLD-034、FLD-047、FLD-048、FLD-049、FLD-050、FLD-051；权限口径见 SRC-016、FLD-005、FLD-031。

4）逻辑说明：标准版默认 5,000 元、365 天、10,000 分钟；话费充值包默认 1,000 元/包、3,500 分钟/包，数量为正整数；试用套餐默认 0 元、30 天、500 分钟，仅试用租户可开通。实际套餐总价支持 0 元和最多两位小数；实际天数和分钟必须为大于 0 的整数。价格、天数或分钟任一值偏离默认值时原因必填。包数变化只联动未手改的总价和分钟，已手改值保留。账户和流水作为同一写账结果生效，写账中断时两者均不生成成功结果。

3. 充值管理 - 手工调增与调减

1）功能名称：使用时长与可用分钟手工调整。

2）交互说明：超级管理员选择调增或调减，再选择使用时长或可用分钟，输入正整数和业务原因。页面实时展示当前值、最多可调减值、冻结分钟及调整结果，确认后写入调整流水。

3）数据来源：SRC-002、SRC-004、SRC-005；FLD-009、FLD-020、FLD-021、FLD-022、FLD-029 至 FLD-040；权限口径见 SRC-016、FLD-005、FLD-031。

4）逻辑说明：支持“调增/调减 × 使用时长/可用分钟”四种组合。分钟调减上限为当前可用分钟；时长调减保留合法下限；任何调整都不直接修改已冻结分钟。打开表单时记录账户版本，提交前版本变化则要求刷新后重新确认。

4. 外呼任务 - 统一分钟池冻结与结算

1）功能名称：统一分钟池预冻结、消耗、释放与幂等处理。

2）交互说明：外呼任务提交时检查并预冻结估算分钟；收到呼叫结果后按是否接通计算分钟；任务完成结算实际消耗并释放余量，任务终止则释放全部未结算冻结。

3）数据来源：SRC-004、SRC-006、SRC-007；FLD-021、FLD-022、FLD-023、FLD-034；权限口径见 SRC-016、FLD-005、FLD-031。

4）逻辑说明：只有可用分钟足够才允许冻结。未接通计 0 分钟；已接通按通话时长向上取整，不足 1 分钟按 1 分钟。完成、终止及重复回调都以同一租户统一分钟池为账本边界，重复处理不再次变更余额。
