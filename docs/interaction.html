四. 功能说明

1. 外呼列表 - 大众通信任务详情 - 重呼追溯

1）功能名称： 大众通信重呼追溯

2）交互说明： 用户从外呼列表点击“查看”，切换到“任务详情”后只读查看。定时重呼显示重呼方式、计划重呼次数和人工配置确认；任务重呼显示重呼方式和风险知情确认。页面不再展示确认记录、当前呼叫轮次或是否最后一次计划呼叫。

3）数据来源： SRC-001 用户要求、SRC-002 红框截图、SRC-003 当前原型底座；字段使用 FLD-001 至 FLD-004。

4）逻辑说明： 重呼方式决定摘要分支。删除项不会以空行、横线、替代名称或折叠内容继续保留；配置页门禁和业务侧末次判断规则不因本次展示精简而改变。

5）功能明细

功能名称功能说明数据来源取值逻辑数据格式默认值异常处理
重呼方式标识任务采用的重呼策略SRC-003 / FLD-001读取模式枚举并映射中文定时重呼 / 任务重呼未配置缺失显示未配置
计划重呼次数定时重呼计划次数，不含首次SRC-001 / FLD-002仅在定时重呼分支读取正整数N 次（不含首次）--无效或缺失显示横线
人工配置确认声明大众后台配置完成且次数一致SRC-003 / FLD-003定时重呼分支读取确认布尔值已确认 / 尚未确认尚未确认缺失按尚未确认
风险知情确认声明已知悉任务重呼完成态风险SRC-003 / FLD-004任务重呼分支读取确认布尔值已知悉 / 尚未确认尚未确认缺失按尚未确认
