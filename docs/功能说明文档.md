## 三. 逻辑说明

| 流程名称 | 跳转地址 |
| :--- | :--- |
| **认证与登录链路** | 用户访问系统 → 默认进入登录页（或右上角退出登录进入） → 展示东风日产品牌标识、拓扑网络背景、图形验证码 → 点击登录免校验直达系统首页。 |
| **外呼任务全生命周期** | 业务场景配置 → 生成任务策略（如电声 `strategyCode` 或一知任务） → 导入线索名单（校验预计冻结金额） → 外部平台异步呼叫 → 话单实时回调 → 中台映射统一通话状态与意向级别 → 数据看板与线索报表呈现。 |
| **租户资金与计费流转** | 充值单关联（试用单/付费单） → 生成待生效记录 → 手动点击生效弹窗（按套餐调整天数/金额） → 计入统一资金账户 → 外呼任务创建预冻结 → 任务完成/终止释放冻结并按分钟单价实际扣费。 |
| **意向标签映射流转** | 供应商平台返回原生标签 → 匹配「供应商标签集」 → 根据映射规则转换为「中台标准标签集」 → 驱动线索记录标签打标与数据概览意向洞察统计。 |
| **黑名单跨平台同步** | 中台创建黑名单分组并录入号码 → 触发已启用平台适配器（如电声 `groupCode` 自动建组） → 同步远端号码池 → 呼叫前本地+远端双重拦截。 |

### 4. 外呼场景 - 外呼列表 - 查看 - 数据概览

**1）功能名称：** 单任务外呼数据概览看板  
**2）交互说明：** 进入任务详情默认激活「数据概览」Tab，包含四大区块：
1. **外呼数据**：导入客户数、外呼客户数、去重过滤客户数、总接听率、挂机率、平均通话时长、总外呼数、过滤比例、接听客户数；
2. **意向分类**：展示 A/B 类及 A+B 类客户数及占比，支持点击「配置」按钮自定义关联标签并计算并集；
3. **意向洞察**：展示任务意向等级分布环形图与客户关注点排行条形图（支持点击「全部」弹窗查看完整排名与占比）；
4. **通话时长分布**：展示 0-5s、6-10s、11-30s、31-60s、61-90s、>90s 柱状区间分布。  
**3）数据来源：** 供应商话单回调、百炼智能体 NLP 提取、中台聚合计算。  
**4）逻辑说明：**
- 总接听率 = 接听客户数 (去重) ÷ 外呼客户数 (去重)；
- 过滤比例 = 去重过滤客户数 ÷ 导入客户数；
- 意向分类多标签配置取**并集**去重统计。  
**5）功能明细：**

| 功能名称 | 功能说明 | 数据来源 | 取值逻辑 | 数据格式 | 默认值 | 异常处理 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 导入客户数 | 任务接收的总客户手机号数 (去重) | 中台任务库 | 按手机号去重 count | 整数 | 0 | -- |
| 外呼客户数 | 成功提交至供应商接口的手机号总数 (去重) | 中台任务库 | 接口成功记录去重 count | 整数 | 0 | 提交失败不计入 |
| 去重过滤客户数 | 经黑名单或规则拦截过滤的客户数 (去重) | 中台拦截库 | 状态为已过滤的手机号去重 | 整数 | 0 | -- |
| 总接听率 | 外呼接通转化率 | 聚合计算 | `接听客户数 ÷ 外呼客户数` | 百分比 | 0.0% | 分母为0时显示 0.0% |
| 接听客户数 | 实际产生通话接听的客户数 (去重) | 回调话单 | 话单状态为已接通去重 | 整数 | 0 | -- |
| 平均通话时长 | 成功接听通话的平均建立连接时长 | 回调话单 | `总通话秒数 ÷ 接听总次数` | 秒数 (整型) | 0秒 | -- |
| 意向分类配置按钮 | 弹出意向等级与标签关联配置框 | 前端行为 | 点击弹出配置弹窗 | 点击事件 | -- | -- |
| 意向分布环形图 | 呈现当前任务各意向等级占比分布 | NLP 标签库 | 按 A/B/C/D/E/F 聚合占比 | ECharts 环形图 | 空图表 | 无数据时居中提示暂无数据 |
| 客户关注点排行 | 通话中提及频次最高的前 10 个关注点 | NLP 关键词 | 标签词频降序 Top 10 | 横向条形图 | 0 | 一知总部租户或无数据隐藏 |
| 全部关注点弹窗 | 点击「全部」弹出完整关注点排行榜 | NLP 关键词 | 完整词频降序列表+占比进度条 | 模态弹窗 | -- | 支持滚动浏览 |

### 5. 外呼场景 - 外呼列表 - 查看 - 任务详情

**1）功能名称：** 任务元数据与底层策略查看  
**2）交互说明：** 展示创建日期、话术/机器人名称、任务 ID、任务描述、启动方式（自动/手动）、拨打时段（星期与时间段）、风控策略（频次限制与黑名单策略）、自动重拨设置（重拨间隔与最大次数）。右上角提供「终止任务」操作。  
**3）数据来源：** 中台任务库、供应商策略接口。

   - **判断规则**：通过【异步导入客户到外呼任务接口】提交，并通过事件回调接口【API导入外呼任务结果通知回调】获取对应的导入结果。

   - **数据来源**：外部平台话单推送或中台拉取。

> **资金余额预校验复合公式**：  
> 用户导入文件时，系统同时进行**供应商单次硬限制**与**租户可用资金余额**双重校验：
> $$\text{预计冻结金额} = \text{导入有效号码数} \times \text{单号码预计分钟 (默认2分)} \times \text{当前有效单价} \le \text{当前可用资金余额}$$
> 若超限则拒绝导入，并明确提示最大允许导入数量：
> $$\text{最大允许导入数} = \min\left(\text{当前供应商单次上限},\; \lfloor \frac{\text{当前可用资金余额}}{\text{单号码预计分钟} \times \text{有效单价}} \rfloor\right)$$

  - **需要映射黑名单的智能平台由开发后台统一配置，业务平台前端不提供配置功能**；
  - 业务用户仅负责在前端录入、维护黑名单分组与号码，系统底层自动读取后台预设的供应商同步通道执行下发与状态回写；
- **平台同步与移除**：移除号码时需先同步解除各外部平台远端黑名单，全部成功后再清除本地；含号码的分组禁止直接删除。

### 3. 租户充值计费、资金数学模型与生命周期

1. **账户资金平衡公式**：
   $$B = R - D - C$$
   $$A = \max(B - F, 0)$$
   - $R$：已生效通话充值总额（仅已支付且手动生效的通话费单与组合单计入，坐席费仅更新有效期）；
   - $D$：累计手工扣减金额；
   - $C$：累计实际通话消费金额；
   - $B$：当前资金总余额；
   - $F$：当前有效冻结总额；
   - $A$：当前统一可用金额（页面内部隐藏，作为换算与校验基准）。

2. **模型可用分钟换算（不同模型分钟数不可相加）**：
   $$M_{LA} = \lfloor \frac{A}{P_L} \rfloor \quad (\text{大模型可用分钟数，} P_L \text{ 为大模型有效单价})$$
   $$M_{SA} = \lfloor \frac{A}{P_S} \rfloor \quad (\text{小模型可用分钟数，} P_S \text{ 为小模型有效单价})$$

3. **冻结、结算与释放生命周期**：
   - 单任务预计冻结金额：$F_i = \text{预计通话分钟数} \times p_i$；
   - 任务完成时实际消费：$C_i = m_{a,i} \times p_i$（$m_{a,i}$ 为实际通话分钟数，$p_i$ 为单价快照）；
   - 未使用冻结金额：$U_i = \max(F_i - C_i, 0)$；
   - 结算后新余额：$B' = B - C_i$，结算后新冻结：$F' = F - F_i$；
   - **自动解冻机制**：任务完成、任务终止、或冻结创建满 **24 小时**，系统自动解除冻结占用，保证幂等。

4. **手工扣减与线下调整**：
   - 线下坏账或特殊冲减通过「余额调整」录入，扣减上限为当前资金余额（$\text{扣减金额} \le \text{当前资金余额}$）；
   - 手工扣减流水永久记录，不可撤销或删除。

### 5. 线索回流统计与数据脱敏安全规范

1. **线索回流统计看板**：
   - 追踪业务系统（DCC/线索中心）传入、提交外呼和回传业务系统的全链路漏斗；
   - 包含统计时间（date 粒度）、场景名称、线索传入数、提交外呼数、线索回流数、回流转化率等指标。
2. **手机号掩码脱敏**：
   - 列表表格、通话记录、线索明细及弹窗展示中，所有客户手机号码一律统一处理为 **`前3位 + 4个星号 + 后4位`**（例如 `138****8888` 或 `159****5393`）；
   - 导出 CSV/Excel 时根据当前登录操作员权限决定是否解密导出。
3. **多租户数据强隔离**：
   - 门店租户登录仅可查看并操作本租户下的场景、账号、任务与名单；
   - 总部超管（`产品-超管`）具备全局租户切换、跨平台统一配置与底层标签映射管理权限。
