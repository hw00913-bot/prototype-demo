## 三. 逻辑说明

| 流程名称 | 跳转地址 |
| :--- | :--- |
| **认证与登录链路** | 用户访问系统 → 默认进入登录页（或右上角退出登录进入） → 展示东风日产品牌标识、拓扑网络背景、图形验证码 → 点击登录免校验直达系统首页。 |
| **外呼任务全生命周期** | 业务场景配置 → 生成任务策略（如电声 `strategyCode` 或一知任务） → 导入线索名单（校验预计冻结金额） → 外部平台异步呼叫 → 话单实时回调 → 中台映射统一通话状态与意向级别 → 数据看板与线索报表呈现。 |
| **租户资金与计费流转** | 充值单关联（试用单/付费单） → 生成待生效记录 → 手动点击生效弹窗（按套餐调整天数/金额） → 计入统一资金账户 → 外呼任务创建预冻结 → 任务完成/终止释放冻结并按分钟单价实际扣费。 |
| **意向标签映射流转** | 供应商平台返回原生标签 → 匹配「供应商标签集」 → 根据映射规则转换为「中台标准标签集」 → 驱动线索记录标签打标与数据概览意向洞察统计。 |
| **黑名单电声平台同步** | 中台创建黑名单分组并录入号码 → 在“平台同步设置”中启用电声平台 → 电声适配器按 `groupCode` 建立映射并同步远端号码池 → 呼叫前本地+电声远端双重拦截。 |

### 3. 外呼场景 - 外呼列表

**1）功能名称：** 外呼任务卡片与列表调度管理  
**2）交互说明：** 顶部提供任务名称、智能平台（一知/科大/冰兰/中科金/电声）、场景类型、创建时间等多条件筛选与重置；下方以任务卡片矩阵形式展示任务状态、数据来源、平台标识；卡片提供「查看」「编辑」「终止」「暂停」「删除」等操作。  
**3）数据来源：** 中台任务库及各供应商平台任务回调。  
**4）逻辑说明：** 所有平台原始任务状态先映射到中台 13 项 `TaskExecuteStatus` 后再参与展示和筛选；电声 `statusType=1 (ENABLED)` 映射“可运行”，`statusType=0 (FROZEN)` 映射“系统暂停”，不得与批次生命周期字段 `executeStatus` 混用。完整映射见“五. 其他说明 → 1. 外呼任务统一状态与六平台映射”。平台返回未知值时保留原始值并显示“未映射”，禁止兜底为“未启动”。
**5）功能明细：**

| 功能名称 | 功能说明 | 数据来源 | 取值逻辑 | 数据格式 | 默认值 | 异常处理 |

### 6. 外呼场景 - 外呼列表 - 查看 - 呼叫名单与手动导入

**1）功能名称：** 呼叫名单状态流转、手工异步导入与错误重试机制  
**2）交互说明：**  
- **名单子 Tab**：包含「已分配」「待呼叫」「已呼叫」「已过滤」「呼叫失败」5 个状态子标签；  
- **待呼叫操作**：支持点击「终止外呼」展示复选框，勾选后批量移出待呼叫队列并弹出二次确认；  
- **呼叫失败列表交互**：列表按号码提交时间倒序排列，展示用户号码、提交时间、失败原因（`errMsg`）；  
- **手动导入显示前置条件**：仅当当前外呼任务关联的业务场景已将“数据导入方式”设置为“手动导入”时，页面才显示「手动导入」入口；设置为“自动传入”或“接口传入”时不显示该入口；
- **手动导入弹窗**：点击「手动导入」弹出大弹窗（1040px），包含「上传文件」与「导入记录」两个 Tab：
  - **上传文件 Tab**：拖拽或选择 Excel/CSV 文件，自动校验单次号码上限，并按预计消耗校验租户可用资金余额；
  - **导入记录 Tab**：列表呈现历史批次、文件名、总数、成功数、失败数、导入时间与操作；提供「导出失败记录」按钮（自动生成带 UTF-8 BOM 的 CSV 文件）。  

**3）各名单数据来源与取值逻辑（水滴标记规范）：**
1. **已分配号码名单（水滴标记 10）**：
   - **数据来源**：1. 手动导入：导入成功的号码；2. 自动传入：取业务场景传入的外呼账号。
   - **取值逻辑**：见流程【呼叫流程】，号码导入/传入落库后初始处于已分配状态。
2. **待呼叫号码名单**：
   - **数据来源**：对接外部外呼系统【异步导入客户到外呼任务接口】。
   - **取值逻辑**：将已分配的手机号通过接口传入到外部智能外呼系统；当接收到回调后，如果回调结果为导入失败的，号码移到呼叫失败列表；如果回调结果为导入成功的，号码展示在待呼叫直到号码已呼叫。
   - **判断规则**：通过【异步导入客户到外呼任务接口】提交，并通过事件回调接口【API导入外呼任务结果通知回调】获取对应的导入结果。
3. **已呼叫号码名单（水滴标记 15）**：
   - **数据来源**：外部平台话单推送或中台拉取。
   - **取值逻辑**：通过【通话记录同步接口】获取单个任务 id 的通话记录与话单详情。
4. **已过滤号码名单（水滴标记 16）**：
   - **数据来源**：中台黑名单/规则拦截库及外部平台过滤回调。
   - **取值逻辑**：通过【过滤客户回调接口】获取到任务的过滤手机号及拦截原因。
5. **异步导入失败的手机号列表（呼叫失败）**：
   - **数据来源**：从【API 导入外呼任务结果通知回调】接口获取对应的导入失败记录。
   - **字段映射**：用户号码对应 `phoneNumber`；号码提交时间对应任务 id+批次号提交到接口的时间；失败原因对应 `errMsg`。
   - **自动重试判断规则**：
     - ① 失败数据，每 **30 分钟**系统自动重新提交一次；
     - ② 当天最终失败的数据，隔天不再重试，将最后一条失败数据回传给业务系统；
     - ③ 如果提交一知后，回调返回“客户已存在”就不要下发给 dcc。

**4）各供应商手机号导入限制规范（来自 WIKI 知识库基线）：**

| 智能外呼供应商 | 导入接口与鉴权方式 | 单次号码导入上限 | 批次与调度模式 | 超限处理与界面提示 |
| :--- | :--- | :--- | :--- | :--- |

> **资金余额预校验复合公式**：  
> 用户导入文件时，系统同时进行**供应商单次硬限制**与**租户可用资金余额**双重校验：
> $$\text{预计冻结金额} = \text{导入有效号码数} \times \text{单号码预计分钟 (默认2分)} \times \text{当前有效单价} \le \text{当前可用资金余额}$$
> 若超限则拒绝导入，并明确提示最大允许导入数量：
> $$\text{最大允许导入数} = \min\left(\text{当前供应商单次上限},\; \lfloor \frac{\text{当前可用资金余额}}{\text{单号码预计分钟} \times \text{有效单价}} \rfloor\right)$$

- 场景删除时自动校验是否被运行中外呼任务引用。  

**大众通信重呼规则：**

1. “计划重呼次数”仅统计重呼，不含首次呼叫；最大呼叫轮次 = 计划重呼次数 + 1。例如填写 2，最多计划 1 次首呼和 2 次重呼，共 3 次。
2. 定时重呼保存门禁包含：计划重呼次数为大于等于 1 的整数、人工配置确认已勾选。勾选确认时记录确认人和确认时间。
3. 主任务 UUID、重呼方式或计划重呼次数任一发生变化，原人工确认立即失效，必须再次核对大众后台后重新确认。
4. 任务重呼存在主任务完成后不再触发待重呼号码的风险，必须完成显式知情确认后才能保存。
5. 因大众定时重呼暂无接口，正式实现也不得将人工确认展示为“接口校验成功”。

**电声重呼与 `days` 换算规则（创建任务提交接口前）：**

1. 定时启动以 `autoStart.executeDateTime` 为计划开始时间；立即启动以中台提交创建任务请求时的系统时间为计划开始时间，不依赖实际呼叫结果或回调。
2. 页面的“最大呼叫次数”直接对应 `maxAttempts`，含首呼；若为 `M`，则中台将统一重呼间隔 `I` 重复 `M - 1` 次，生成 `intervalMinutes = [I, I, ……]`。`M = 1` 时数组为空。
3. 中台从计划开始时间开始模拟排程：第 1 次呼叫取 `nextCallableTime(startAt)`；第 `N` 次呼叫取 `nextCallableTime(第 N-1 次计划时间 + I 分钟)`，直到得到 `M` 个计划呼叫时间。
4. `nextCallableTime` 必须同时检查 `callTimeWindow.windows`、可呼叫星期和 `excludeDates`：时间早于当天首个窗口时移到该窗口开始，落在窗口间隔时移到当天下一个窗口，晚于最后窗口、星期不可呼或命中排除日期时，按 `onOutOfWindow = postpone` 顺延至下一个可呼叫日的首个窗口。
5. 得到最后一次计划呼叫时间后，按自然日包含首尾计算：`days = 最后一次计划呼叫日期 - 任务计划开始日期 + 1`。周末、禁呼日和排除日期不发起呼叫，但仍计入自然日跨度。
6. 换算完成后，中台将 `days`、`maxAttempts` 和 `intervalMinutes` 一并放入电声创建任务请求。找不到可呼叫时间或预估超过 365 个自然日时，阻止提交并提示调整呼叫窗口、排除日期或重呼配置。

### 4. 租户充值计费、资金数学模型与生命周期

1. **账户资金平衡公式**：
   $$B = R - D - C$$
   $$A = \max(B - F, 0)$$
   - $R$：已生效通话充值总额（仅已支付且手动生效的通话费单与组合单计入，坐席费仅更新有效期）；
   - $D$：累计手工扣减金额；
   - $C$：累计实际通话消费金额；
   - $B$：当前资金总余额；
   - $F$：当前有效冻结总额；
   - $A$：当前统一可用金额（页面内部隐藏，作为换算与校验基准）。

2. **模型可用分钟换算（不同模型分钟数不可相加）**：
   $$M_{LA} = \lfloor \frac{A}{P_L} \rfloor \quad (\text{大模型可用分钟数，} P_L \text{ 为大模型有效单价})$$
   $$M_{SA} = \lfloor \frac{A}{P_S} \rfloor \quad (\text{小模型可用分钟数，} P_S \text{ 为小模型有效单价})$$

3. **冻结、结算与释放生命周期**：
   - 单任务预计冻结金额：$F_i = \text{预计通话分钟数} \times p_i$；
   - 任务完成时实际消费：$C_i = m_{a,i} \times p_i$（$m_{a,i}$ 为实际通话分钟数，$p_i$ 为单价快照）；
   - 未使用冻结金额：$U_i = \max(F_i - C_i, 0)$；
   - 结算后新余额：$B' = B - C_i$，结算后新冻结：$F' = F - F_i$；
   - **自动解冻机制**：任务完成、任务终止、或冻结创建满 **24 小时**，系统自动解除冻结占用，保证幂等。

4. **手工扣减与线下调整**：
   - 线下坏账或特殊冲减通过「余额调整」录入，扣减上限为当前资金余额（$\text{扣减金额} \le \text{当前资金余额}$）；
   - 手工扣减流水永久记录，不可撤销或删除。

### 6. 线索回流统计与数据脱敏安全规范

1. **线索回流统计看板**：
   - 追踪业务系统（DCC/线索中心）传入、提交外呼和回传业务系统的全链路漏斗；
   - 包含统计时间（date 粒度）、场景名称、线索传入数、提交外呼数、线索回流数、回流转化率等指标。
2. **手机号掩码脱敏**：
   - 列表表格、通话记录、线索明细及弹窗展示中，所有客户手机号码一律统一处理为 **`前3位 + 4个星号 + 后4位`**（例如 `138****8888` 或 `159****5393`）；
   - 导出 CSV/Excel 时根据当前登录操作员权限决定是否解密导出。
3. **多租户数据强隔离**：具体角色数据范围与模块权限统一见下一节“统一角色权限说明（唯一维护出处）”。
