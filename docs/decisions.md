## D-002 删除大众定时重呼任务 ID

- 决策：删除“关联重呼任务 ID”输入、数据属性、保存校验、详情行、文档和标注字段。
- 依据：SRC-001 明确大众通信 SaaS 后台不提供该 ID；SRC-002 红框指定删除区域。
- 保留：计划重呼次数、定时配置人工确认、确认人/时间、任务重呼风险确认和末次判断。
- 文案：人工确认只表达“已完成大众后台定时重呼配置，且计划重呼次数与实际一致”。
- 禁止：不新增替代 ID、不保留隐藏字段、不声称中台已通过接口自动校验。
