# 任务计划

## 项目目标

- 将大众通信任务详情的重呼追溯区精简为配置摘要，删除确认记录、当前呼叫轮次和末次判断。
- 同步功能说明、交互说明和标注口径，保持场景配置页能力不变。

## 阶段计划

1. 修改大众任务详情渲染，删除三项展示和详情页专用计算。
2. 修订功能说明，移除任务详情轮次追踪与末次判断口径。
3. 对定时重呼、任务重呼示例及配置页执行浏览器回归。
4. 完成全局验证并准备标注更新提示词和交互说明。

## 当前优先级

- P0：红框三项在任务详情中完全消失。
- P0：重呼方式、计划重呼次数、人工配置确认仍正确展示。
- P1：说明与标注不再引用已删除能力。

## 风险与依赖

- 依赖现有 `scene-list.js` 详情弹窗和 `scene-list-dazhong-redial` 标注锚点。
- 删除 DOM 行后需确认弹窗布局自然收缩，无空白占位。
- 配置页确认门禁不在修改范围，只做回归验证。
