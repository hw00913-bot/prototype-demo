## 项目目的

- 实现目的：把租户充值升级为“标准版年包 + 话费充值包 + 内部手工调整”的统一分钟池方案，去除新充值对外部充值单号的依赖，并提供当前租户两级使用明细。
- 评审对象：产品经理、研发、测试及参与充值、账本和租户权限评审的业务人员。
- 需要验证的业务假设：管理员能以默认套餐值或手工编辑值完成充值；内部流水能替代外部单号形成追溯；统一分钟池能与原有冻结/消耗闭环衔接；普通租户用户能查看当前租户用量且不会越权。
- 不属于本次验证目标：真实支付、真实账本/API 联调、历史数据迁移执行、商用/试用差异化计费、超级管理员使用明细、生产级并发和性能。

## 项目范围

- 本期模块：租户管理、充值管理、手工调整、当前租户使用情况、通讯额度账本展示。
- 本期页面：租户管理列表与编辑、租户充值管理、套餐开通与充值包表单、手工调增/调减弹窗、当前租户使用情况与按日明细、每日任务通话分钟消耗明细。
- 本期能力：
  - 租户新增商用/试用标记，标记只用于识别和展示。
  - 标准版默认 5,000 元/店、默认 365 天、默认 10,000 分钟。
  - 话费充值包默认 1,000 元/包、每包 3,500 分钟，有效服务期内支持多包和多次叠加。
  - 使用时长按天、入账分钟数均可手工编辑；两者必须为大于 0 的整数，偏离默认值必须填写原因，无额外审批。
  - 标准版、充值包和手工分钟调整全部进入大/小模型共享的租户级统一分钟池。
  - 新充值不要求外部充值单号，系统生成内部流水并展示完整审计字段。
  - 手工调增和调减均可调整使用时长或可用分钟，调减不得篡改已有冻结记录或减为负数。
  - 右上角为普通租户用户提供当前登录租户有效期、可用分钟、按日消耗和任务级二级明细；超级管理员不显示入口。
- 核心流程：
  1. 维护租户商用/试用标记 → 开通标准版或购买充值包 → 写入统一分钟池和内部流水 → 在充值管理中核对。
  2. 外呼任务预冻结 → 已接通通话按分钟消耗 → 完成/终止时结算和释放 → 使用情况按日/任务展示。
  3. 选择调增/调减及调整对象 → 输入数值和原因 → 预览调整前后值 → 校验边界 → 写入调整流水。

## 整体页面结构

- 导航结构：
  - 系统管理 → 租户管理 → 充值管理。
  - 租户管理编辑区维护商用/试用标记。
  - 充值管理内进入新增充值和手工调整。
  - 右上角 → 使用情况 → 按日明细 → 每日任务明细。
- 页面列表：
  1. 租户管理列表与编辑。
  2. 租户充值管理。
  3. 套餐开通与充值包表单。
  4. 手工调增/调减弹窗。
  5. 当前租户使用情况与按日明细。
  6. 每日任务通话分钟消耗明细。
- 页面跳转关系：租户列表打开充值管理；充值管理打开新增充值或手工调整；普通租户用户从全局右上角进入使用情况，再由某日记录下钻至任务明细并可返回。
- 页面职责：管理端负责标记、充值、调整和审计；租户端负责查看当前租户有效期、统一分钟余额和消耗明细；任务侧只通过展示冻结/结算结果证明原有规则仍被保留。

## 核心流程

- 用户入口：充值管理员从租户管理进入充值管理；平台管理员在租户编辑中维护标记；普通租户用户从右上角进入使用情况。
- 主流程步骤：
  1. 选择租户并查看标记、服务期、可用/冻结分钟。
  2. 选择标准版或充值包，载入默认值，必要时编辑天数/分钟并填写原因。
  3. 提交后展示统一分钟池变化及系统自动生成的内部流水。
  4. 发起手工调整时选择方向和对象，预览前后值，完成边界校验并记录流水。
  5. 普通租户用户查看当前租户用量，按日下钻到任务级消耗。
- 关键状态：未开通、有效、已过期；编辑中、校验失败、处理中、已生效、失败；可用、已冻结、已消耗、已释放。
- 异常或空状态：无充值历史、无按日数据、无任务明细、加载失败可重试、字段非正整数、偏离默认值缺少原因、服务期无效、调减越界、账本版本冲突、超级管理员入口隐藏、请求租户与当前登录租户不一致。

## 验收方向
