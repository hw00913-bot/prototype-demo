# 已确认业务规则

## 业务对象定义

- 大众主任务：通过 UUID 与中台业务场景关联的外呼任务，不等同定时重呼承接任务。
- 定时重呼：由操作人在大众通信 SaaS 后台完成配置，中台不获取定时重呼任务 ID。
- 任务重呼：继续使用主任务内重呼，存在主任务完成后待重呼不再触发的风险。
- 计划重呼次数：大众后台实际配置的重呼次数，不含首次呼叫。
- 人工确认：操作人声明已完成大众后台定时重呼配置且计划重呼次数与实际一致。

## 关键字段含义

- 大众主任务 ID：保留的场景关联 UUID。
- 是否需要重呼：控制重呼配置分支显隐。
- 重呼方式：定时重呼或任务重呼，默认推荐定时重呼。
- 计划重呼次数：大于等于 1 的整数，不含首次。
- 配置确认：定时重呼保存门禁，勾选时记录确认人和确认时间。
- 风险确认：任务重呼保存门禁。
- 定时重呼任务 ID：不存在于当前产品字段，不输入、不保存、不展示、不校验。

## 主要状态和枚举

- 重呼开关：不需要 / 需要。
- 重呼方式：scheduled=定时重呼；task=任务重呼。
- 定时配置确认：尚未人工确认 / 已人工确认。
- 任务风险状态：尚未知悉 / 已知悉。
- 末次结论：是，已到计划上限 / 否，仍有计划重呼 / 无法判断。

## 计算与失效规则

- 最大呼叫轮次 = 计划重呼次数 + 1。
- 当前呼叫轮次大于等于最大呼叫轮次时，判定为最后一次计划呼叫。
- 主任务 UUID、重呼方式或计划重呼次数变化时，原定时配置确认、确认人和确认时间失效。
- 删除关联任务 ID 后，不再存在由该字段触发的确认失效或保存错误。

## 权限或角色边界

- 具备业务场景维护权限的用户可配置并人工确认。
- 具备任务查看权限的用户只读查看确认记录和轮次判断。
- 人工确认不代表系统从大众接口校验成功。

## 异常、空状态或边界规则

- 定时重呼下计划次数为空、小数或小于 1 时阻止保存。
- 定时重呼下未勾选人工确认时阻止保存。
- 任务重呼下未勾选风险确认时阻止保存。
- 详情缺少计划次数或当前轮次时显示“无法判断”。
- 页面和文档不得出现“关联重呼任务 ID 为空”类错误。
