## 产品目标

2026-09-05 评审修正（SRC-012 / D-011）：去除充值管理冻结结算展示区；试用租户明确提供使用套餐开通入口；本次套餐总价可手工编辑；使用情况移入账户下拉；首页新增当前租户套餐、有效期、统一分钟池概览，读取同一账户数据。以该修正覆盖下文相同范围的旧入口及价格描述。

将租户充值升级为“标准版年包 + 话费充值包 + 内部手工调整”方案。新充值不依赖外部充值单号，由系统生成内部流水；标准版、充值包和手工分钟调整统一进入租户级分钟池，由大模型和小模型外呼共同冻结、释放和消耗。同时保留现有额度生命周期，并向普通租户用户提供当前登录租户的有效期、可用分钟、按日消耗和任务级二级明细。

## 目标用户

- 平台管理员：在租户新建、编辑和列表中维护、查看商用/试用标记。
- 超级管理员：开通标准版、购买话费充值包、查看内部流水、手工调增或调减。
- 租户运营人员：继续通过原有外呼任务链路触发分钟冻结、消耗和释放。
- 普通租户用户：通过右上角“使用情况”查看当前登录租户的有效期和用量。
- 超级管理员：用于验证“使用情况”入口不可见，不提供租户用量明细。

## 核心页面列表

1. PAGE-001 租户管理列表与编辑：维护商用/试用标记，展示有效期和可用分钟概览。
2. PAGE-002 租户充值管理：展示套餐、统一分钟池、冻结额度、内部充值记录和调整流水。
3. PAGE-003 套餐开通与充值包表单：选择标准版或充值包，编辑使用天数和入账分钟。
4. PAGE-004 手工调增/调减弹窗：选择方向、对象、数值和原因，预览调整前后值。
5. PAGE-005 当前租户使用情况与按日明细：展示有效期、可用分钟和按日消耗。
6. PAGE-006 每日任务通话分钟消耗明细：展示所选日期各任务的消耗及当日合计。

## 核心用户路径

- 路径 A：租户管理 → 设置商用/试用标记 → 打开充值管理 → 开通标准版或购买充值包 → 校验表单 → 更新统一分钟池 → 生成内部流水。
- 路径 B：租户充值管理 → 发起手工调整 → 选择调增/调减和使用时长/可用分钟 → 填写值与原因 → 校验边界 → 更新账户并生成调整流水。
- 路径 C：普通租户用户右上角“使用情况” → 查看当前租户有效期与可用分钟 → 查看按日消耗 → 下钻某日任务明细 → 核对当日合计。
- 路径 D：外呼任务提交 → 统一分钟池预冻结 → 接通后按分钟计量 → 完成/终止时结算并释放未消耗冻结。

## 主要数据对象

- Tenant：租户身份、名称、商用/试用标记和当前登录租户上下文。
- ServiceEntitlement：服务生效时间、失效时间、使用天数和有效状态。
- MinutePool：租户级统一分钟池的可用、冻结、已消耗和已释放分钟。
- RechargeProduct：标准版年包与话费充值包的价格、默认天数、默认分钟和数量。
- RechargeRecord：系统生成的内部充值流水及完整审计字段。
- AdjustmentRecord：手工调增/调减的方向、对象、数值、前后值、原因和操作信息。
- DailyUsage：按日期汇总的通话分钟消耗。
- TaskUsage：某日期下按外呼任务拆分的消耗分钟及合计关系。
- AuthContext：当前账号角色、当前租户和权限边界。

## 已确认假设

- 标准版默认 5,000 元/店、365 天、10,000 分钟。
- 话费充值包默认 1,000 元/包、3,500 分钟，服务期内可多包和多次叠加。
- 充值表单使用时长按天、入账分钟数均为大于 0 的整数；偏离默认值必须填写原因，无额外审批。
- 商用/试用只作标记，所有租户采用同一充值、冻结和消耗规则。
- 标准版、充值包和手工分钟调整进入同一租户级分钟池，大/小模型共同使用。
- 新充值、手工调整不依赖外部充值单号，系统生成内部流水号。
- 手工调增与调减均支持使用时长和可用分钟；调减不修改已有冻结记录且不得减为负数。
- 普通租户用户只能查看当前登录租户；超级管理员不提供使用情况入口。
- 已接通通话不满 1 分钟按 1 分钟消耗；原有冻结、释放和结算闭环保留。

## 原型处理假设

- 未到期提前续费/叠加不演示；标准版只演示首次开通和已过期后重新开通。
- 无生产历史兼容需求，不提供旧单号/金额展示或迁移（SRC-015）。
- 话术修改幅度正好 50% 仅展示套餐说明，不实现自动判定。
- 当前内部流水正常展示并保留空态，旧兼容事项已关闭（SRC-015）。
