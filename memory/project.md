# 项目记忆

## 项目定位

- 项目名称：大众定时重呼移除关联任务 ID
- 当前迭代：大众定时重呼移除关联任务ID。
- 创建日期：2026-09-02
- 类型：无构建步骤的静态前端原型
- 入口：`index.html`

## 产品目标

- 删除“关联重呼任务 ID”输入、数据、校验、详情和文档口径。
- 保留定时重呼/任务重呼选择、计划重呼次数、人工配置确认和最后一次计划呼叫判断。
- 页面不得暗示中台可以获取、创建或校验大众定时重呼任务 ID。

## 目标用户

- 总部超管和租户运营：维护大众通信业务场景。
- 外呼任务查看人员：在任务详情追溯计划次数、确认记录和末次判断。
- 研发与测试：依据说明和标注核对删除范围与残留引用。

## 核心页面列表

- `sys-scene`：大众通信重呼配置，删除关联任务 ID 行。
- `scene-list`：大众通信任务详情，删除关联任务 ID 展示。
- `docs/功能说明文档.md/.html`：删除旧字段和旧保存门禁说明。
- `docs/interaction.html` 与页面标注：同步新字段合同。

## 核心用户路径

- 系统管理 → 业务场景 → 编辑大众通信场景 → 需要重呼 → 定时重呼 → 填写计划重呼次数 → 勾选人工确认 → 保存。
- 外呼场景 → 外呼列表 → 查看大众任务 → 任务详情 → 查看计划次数、确认记录、当前/最大轮次和末次判断。

## 主要数据对象

- 大众主任务 UUID：保留，用于场景关联。
- 重呼开关和重呼方式：保留。
- 计划重呼次数：保留，不含首次，用于最大轮次计算。
- 人工确认记录：保留确认状态、确认人和确认时间。
- 当前/最大呼叫轮次与末次结论：保留。
- 定时重呼任务 ID：删除，不再作为任何页面或数据对象。

## 交付方式

- 静态原型页面、Markdown/HTML 功能说明、交互说明、可追溯标注、验证记录。
- 不提供真实大众通信接口调用。

- 人工确认只声明大众后台配置已完成且次数一致，不等同接口校验。
