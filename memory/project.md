# 项目记忆

## 项目定位

- 项目名称：大众任务详情精简重呼追溯
- 当前迭代：大众任务详情精简重呼追溯。
- 创建日期：2026-09-03
- 类型：无构建步骤的静态前端原型
- 入口：`index.html`

## 产品目标

- 精简大众通信任务详情的重呼追溯区，删除截图红框内的确认记录、当前呼叫轮次、是否最后一次计划呼叫。
- 保留重呼方式、计划重呼次数及人工配置确认状态，场景配置与保存门禁不变。

## 目标用户

- 外呼运营人员：查看任务配置摘要。
- 产品与业务评审人员：核对大众通信重呼方案的页面口径。

## 核心页面列表

- 外呼列表中的大众通信任务详情弹窗。
- 与该详情相关的功能说明、交互说明和页面标注。

## 核心用户路径

- 外呼列表 → 查看大众通信任务 → 打开任务详情 → 查看精简后的“大众通信重呼追溯”。

## 主要数据对象

- 大众通信任务。
- 重呼方式：定时重呼或任务重呼。
- 计划重呼次数：不含首次呼叫。
- 人工配置确认状态或任务重呼风险知情状态。

## 交付方式

- 交付可通过本地 HTTP 服务演示的静态原型，并同步功能说明、交互说明和人工标注数据。

## 已确认假设

- 用户红框仅指向任务详情的三项展示，不要求删除配置页确认门禁或底层记录字段。
- 被删信息不以替代文案、折叠项或隐藏详情继续展示。
- 任务重呼分支沿用既有风险知情状态展示。

## 未确认 open items 引用

- 见 `memory/open-items.md`。

## 目录结构

- `js/components/` — 可复用的 B 端公共组件（如高级搜索、弹窗、分页器）
- `js/pages/` — 具体的业务页面逻辑（如仪表盘、线索列表）
- `assets/css/global.css` — 全局 B 端设计规范与通用组件样式
- `assets/css/app.css` — 应用基础样式与布局
- `config/nav.json` — 菜单路由配置（唯一路由数据源，由 `js/nav.js` 动态渲染）
- `mock/data.js` — 全站 B 端模拟数据集与状态机
- `tools/` — 开发辅助工具脚本

## 工作原则

- 先理解现有代码和业务逻辑，再修改。
- 非必要不修改现有板块内容。
- 业务、Mock、文档、记忆和标注工具分别维护。

## 记忆复核摘要
